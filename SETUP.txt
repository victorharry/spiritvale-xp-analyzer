XP Analyzer
===========

Shows how long until your next class and job level, with XP per hour and a
live rate chart, in a small window you drag over the game.


HOW IT WORKS
------------

The program reads the packets the game server already sends to your computer.
That gives your exact level and XP, with nothing to type in.

Windows needs a permission for that, and the installer already takes care of
it: during setup it downloads and opens Npcap, a network reader. Once only.

  On the Npcap screen, leave this option UNTICKED:
     "Restrict Npcap driver's access to Administrators only"
  The rest can stay as they are.

After that the XP Analyzer opens normally, without asking for anything.


WHAT IF I SKIP NPCAP?

The program still works, but then you have to open it as administrator every
time (right-click the shortcut > Run as administrator). It tells you so in its
own window when that is the case.

It is the same Npcap the Spirit Vale Overlay asks for, with the same options.
If you already use that one, you do not need to install it again.


WHAT IT DOES AND DOES NOT DO
----------------------------

Does:
  - reads network packets that are already arriving on this machine

Does not:
  - never reads or writes the game's memory (there is not one line of code in
    the program capable of it)
  - never sends, injects or modifies any packet
  - never automates anything inside the game: no clicking, no mouse movement,
    no key presses

The capture is passive: this machine's traffic only, read only.


NOTHING SHOWS UP?
-----------------

The window itself tells you what is missing — whether the game is closed,
whether it needs permission, or whether it is just waiting for you to gain XP.

For a detailed check, run the diagnostic:

    python listen.py
