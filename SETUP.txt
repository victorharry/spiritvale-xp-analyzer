XP Analyzer
===========

Shows how long until your next class and job level, with XP per hour and a
live rate chart, in a small window you drag over the game.


WINDOWS WILL ASK FOR PERMISSION
-------------------------------

Every time you open the XP Analyzer, Windows shows a permission prompt. Click
Yes and it works.

That is not optional, and it is not a bug. The program reads the network
packets the game server already sends to your computer — that is where your
exact level and XP come from, with nothing to type in. Windows only lets a
program read the network with administrator rights.

If you would rather not see the prompt, there is a way: install Npcap
(https://npcap.com/#download), a network reader that holds the permission for
you. It is the same one the Spirit Vale Overlay uses. The XP Analyzer picks it
up automatically. That is a manual step and entirely up to you.


WHAT IT DOES AND DOES NOT DO
----------------------------

Does:
  - reads network packets that are already arriving on this machine

Does not:
  - never reads or writes the game's memory (there is not one line of code in
    the program capable of it)
  - never sends, injects or modifies any packet
  - never automates anything inside the game: no clicking, no mouse movement,
    no key presses

The capture is passive: this machine's traffic only, read only. That is also
why it needs the permission — reading the network is a privileged operation
even when you only ever look.


NOTHING SHOWS UP?
-----------------

The window itself tells you what is missing — whether the game is closed,
whether it lacks permission, or whether it is just waiting for you to gain XP.

For a detailed check, run the diagnostic from the source folder:

    python listen.py
